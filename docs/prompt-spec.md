# 提示词生成规范（分镜图）

> 目标：**从源头减少质检重跑**。分镜图是重跑重灾区（教训库 68/73 条），其中「景别」
> 占 45 条。根因是扁平长提示词里硬约束被画面内容稀释。本规范定义分镜提示词的**结构化分节**，
> 由 `comfyui_client.build_storyboard_prompt` 单一实现，守卫 `verify_storyboard_prompt_spec.py` 锁定。

## 分节顺序（固定，不可调换）

| 顺序 | 节名 | 内容 | 是否可选 | 硬约束等级 |
|------|------|------|---------|-----------|
| ① | 【取景】 | 景别（必须严格遵守）+ 机位（必须严格遵守） | 景别可「未指定」，机位可选 | **最高**（最靠前） |
| ② | 【参考图】 | 各参考图绑定什么（角色/物品/场景逐条） | 无参考图时给显式声明 | 高 |
| ③ | 【画面内容】 | 镜头号/场景/动作与画面内容/说话状态/情绪氛围 | 至少含动作描述 | 中 |
| ④ | 【光影】 | 光影氛围（光源引导） | 可选（幂等去重） | 低 |
| ⑤ | 【风格】 | 画面风格声明 | 必填（无风格给兜底声明） | 高 |
| ⑥ | 【禁令】 | 一致性 + 无文字/水印硬禁令 | 必填（最后兜底） | 高 |

## 硬规则

1. **景别/机位必须最靠前、独立成段、加粗强调**，绝不能混在【画面内容】之后。这是「景别 45 次重跑」的
   直接对策——取景级约束一旦被动作描述稀释，模型注意力会优先画动作而跑偏景别。
2. **景别未指定时绝不编一个**（camera 只有机位/运镜时返回「未指定」，交还取景描述），
   否则生成端注入「中景」与画面描述的脚部俯拍互斥，质检端再按中景判不符 → 该镜永远过不了。
   （历史：《蛊真人》ep02 shot_13 脚部俯拍被猜成中景，白烧 6 次 GPU。）
3. **台词严禁写进【画面内容】**：只给「说话状态 + 口型开合」，写进台词会被模型当字幕画出来。
4. **光影幂等**：`_extract_light_hint` 命中但已被 visual_detail/storyboard_prompt_zh 承载时返回空串，
   不重复追加（避免同一束光写两遍放大该要素）。
5. **风格不硬编码**：无 style 时给「画面风格以参考图为准」兜底声明 + warning 日志，让上游补风格。
6. **无文字禁令必须独立成段兜底**，措辞最强硬（含「尤其不得出现 AI生成 标识」）。

## 每节措辞要点

- 【取景】景别段：`景别（必须严格遵守）：{cam_key}——{cam_spec}。`（cam_spec 来自 `camera_spec`，
  生成端与质检端共用同一份标准）。
- 【取景】机位段：`机位（必须严格遵守）：{angle_spec}。`（`camera_angle` 解析，与景别正交）。
- 【参考图】`参考图用途：{逐条}。`；无参考图时 `本镜无参考图，画面主体与风格仅依据下方【画面内容】与【风格】生成。`
- 【禁令】一致性三连（角色脸型/发型/服装/配饰、物品形状/材质/颜色、环境氛围）+ 景别机位回溯 + 无文字。

## 为什么这样能减少重跑

- **结构化分节** → 模型逐节定位，硬约束不再被长文本稀释。
- **景别前置** → 取景约束先入为主，动作描述是「在此景别下」的动作。
- **参考图逐条绑定** → 模型明确「哪张图锁哪个特征」，减少角色/背景不一致（16+11 次）。
- **禁令独立兜底** → 无文字/水印/一致性在最末段用最强措辞再强调一次。

## 改动约定

- 改 `build_storyboard_prompt` 后必须跑 `verify_storyboard_prompt_spec.py`（断言分节顺序、景别前置、
  机位独立、参考图绑定、禁令存在 + 边界镜头：未指定景别/无参考图/无风格）。
- 景别/机位标准改 `SHOT_CAMERA_SPECS`/`_CAMERA_ANGLE_SPECS` 前跑 `verify_camera_framing.py`。
